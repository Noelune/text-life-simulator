# 文字人生模拟器

一个使用 Vite + React + TypeScript 开发的文字版人生模拟器游戏，在现代都市、修仙世界和高武世界中体验不同路线的人生抉择。

## 核心玩法

游戏以“选择世界 -> 创建角色 -> 推进人生 -> 解锁结局”为主线，每一局都会因为角色属性、随机事件和主动行动而产生不同走向。

1. **选择世界**：从现代都市、修仙世界、高武世界中选择本局人生舞台。
2. **创建角色**：填写角色信息，并基于世界规则生成初始属性。
3. **推进阶段**：每次推进都会让人生进入新阶段，属性、日志和局势持续变化。
4. **遇到随机事件**：在关键节点遇到不同事件，通过选项改变角色状态和后续路线。
5. **执行主动行动**：根据当前世界选择修炼、工作、投资、挑战等主动行为，主动塑造人生方向。
6. **达成人生目标**：通过属性成长、事件选择和行动积累完成目标或里程碑。
7. **解锁结局图鉴**：每局结束后记录已达成结局，逐步补全图鉴。

## 当前世界说明

### 现代都市

以现实城市生活为背景，围绕学业、事业、财富、家庭、声望和健康展开。玩家可以走稳定成长路线，也可以尝试高风险投资、事业冲刺或隐藏路线。

### 修仙世界

以修炼、机缘、宗门、法宝和天命为核心。角色需要在资源、悟性、心性和境界之间做取舍，追求飞升、掌控大道，或走向更特殊的命运分支。

### 高武世界

以武道、气血、竞技、秘境和强者秩序为主题。玩家通过训练、挑战、突破和声望积累，逐步从普通武者走向更高层级的战斗人生。

## 主要功能

- **三世界独立数据**：现代都市、修仙世界、高武世界拥有各自的属性、事件、行动、目标和结局。
- **随机事件**：不同阶段会触发世界相关事件，事件选项会影响属性、标签、成就和后续路线。
- **主动行动**：玩家可以在阶段推进之外主动选择行动，强化特定属性或尝试路线突破。
- **人生目标 / 里程碑**：游戏会记录关键成长节点，让每局人生不只是数值变化，也有明确阶段成果。
- **多结局**：根据世界、属性、事件标签和路线选择结算不同结局，包括普通、稀有、隐藏等类型。
- **localStorage 存档**：当前局、结局图鉴、成就和设置保存在本地浏览器中。
- **首页图鉴 / 成就 / 设置**：首页提供继续游戏、结局查看、成就记录和基础设置入口。
- **隐藏开挂模式**：给愿意探索边界的玩家准备的特殊下一局体验。

## 隐藏开挂模式

主页的 logo 不只是装饰。连续点击三次后，会悄悄打开“下一局开挂模式”。

开挂模式只对下一局生效：创建新角色时会注入额外资源和特殊路线标记，本局开始后开关会自动关闭。也就是说，它不会永久污染后续存档；想再次体验，需要回到主页重新触发。

## 本地运行方式

项目使用 npm 管理依赖和脚本。

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

构建生产版本：

```bash
npm run build
```

预览构建结果：

```bash
npm run preview
```

## 项目结构说明

```text
src/
  data/          世界、事件、行动、天赋、里程碑、结局等静态游戏数据
  game/          游戏状态类型、核心引擎、存档读写、隐藏开挂逻辑
  components/    首页、角色创建、游戏界面、图鉴和设置面板等 React 组件
  styles.css     全局样式、布局、响应式和界面视觉规则
```

关键目录说明：

- `src/data`：维护游戏内容数据，是扩展新事件、新行动、新结局的主要位置。
- `src/game`：维护核心规则，包括创建人生、推进阶段、执行行动、结算结局和存取档。
- `src/components`：维护玩家可见界面，包括首页、角色创建页、游戏主界面和侧边面板。
- `src/styles.css`：维护整体视觉、布局、卡片、按钮、移动端适配等样式。

## 存档说明

游戏存档保存在浏览器 `localStorage` 中，包括当前局进度、结局图鉴、成就和开关状态。

清除浏览器数据、更换浏览器、使用无痕模式或手动清理站点数据，都会导致存档、图鉴和成就丢失。项目运行不需要联网，也不会把存档上传到服务器。

## 后续开发建议

- **路线系统**：把关键选择沉淀为更明确的路线，让玩家能围绕职业、宗门、武道流派等方向规划人生。
- **连续剧情链**：让部分事件拥有前置和后续，形成更强的因果感和叙事回报。
- **数据校验**：为事件、行动、结局条件增加校验脚本，减少内容扩展时的字段遗漏或条件错误。
- **更多事件和结局**：继续扩充三大世界的随机事件、隐藏分支、失败结局和高成就结局。
- **移动端体验增强**：优化小屏幕下的操作区、日志阅读、图鉴筛选和长文本展示。
